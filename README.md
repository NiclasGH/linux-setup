# Linux Setup
Alternatively, the ansible repo can be used.
This is a repository for a quick setup of fedora. There are 2 scripts in the root directory:

* init.sh: This script is meant to be run only once. It is usually copied from github and then run locally. It sets up ssh with github, does the most basic required git config, pulls the repository and sets up all the aliases
* script.py: This is a larger aggregation of scripts. With this python you can customize what you need installed. This includes programming languages but also normal applications.

## Requirements
You need python to be able to run the setup.py script.
